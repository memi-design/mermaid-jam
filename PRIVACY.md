# Privacy Policy

Mermaid Jam is local-only.

- The plugin does not make network requests.
- The plugin does not use analytics.
- The plugin does not use external AI services.
- The plugin does not collect, sell, or transmit personal data.
- Mermaid source is stored only as Figma plugin data on generated FigJam nodes so users can load and update their own generated diagrams.

If a user deletes generated Mermaid Jam sections/nodes from their FigJam file, the associated plugin data is deleted with those nodes.
