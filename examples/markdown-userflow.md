# New Casual Fan

## Entry
- Sees sign-in screen
- Taps Continue as guest
- Lands on Games

## First value
- Browses today's games
- Opens a game card

## Friction
- Tries to rate or bookmark
- Sees Join Buzzr prompt

Primary success: finds a game and understands what Buzzr is for within 60 seconds.
Main frustration: the first high-intent action asks for an account before the social payoff is obvious.
