## Longer Post

Mermaid is great for writing diagrams quickly, but most design workflows need editable boards, not static renders.

Mermaid Jam bridges that gap. Paste Mermaid or markdown into FigJam and generate native editable cards, sections, and dynamic connectors. It supports flowcharts, journeys, sequence diagrams, state diagrams, mindmaps, timelines, and markdown userflow notes.

The plugin stays local-only: no accounts, no Supabase, no analytics, no AI service, and no network access. It includes line-level diagnostics, local revise/formatting, layout presets, connector routing controls, semantic styling, journey score views, and update-in-place with manual layout preservation.
